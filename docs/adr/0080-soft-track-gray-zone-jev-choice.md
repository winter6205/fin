# 0080. Optional Jev hints for Soft-Track gray-zone routing

Date: 2026-09-21
Status: accepted

Amended 2026-10-16 after operator confirmation and fresh architecture review: retain rules-first routing and the TypeSafe **Jev** closed-set Choice over `dialogue | clarify | off_topic | grounded` as an optional ambiguous-tier hint. A usable hint has finite confidence in `[0,1]` at least `0.6`. Missing configuration, exceptions, malformed output and unusable/low-confidence hints fall back to authorized retrieval, recording route source `fallback`. A clarify hint needs an actionable missing user condition; judge uncertainty and missing financial slots alone do not justify clarification. Policy and source checks, grounded semantic support, code-only citation admission and numeric checks remain mandatory. No second text-model classifier is introduced; the configured answer model still writes answers and ranking stays behind the retrieve port.

Default pytest injects Fake Choice. A changed configured Jev path requires a live real Choice round-trip as separate evidence; a missing optional judge is independently tested as an intended retrieval path and does not block that path's acceptance. Fake evidence never counts as live. Search-mode Choice under ADR 0081 is unchanged. The [route spec](../../specs/soft-track-judge-route.md) and [grounded contract](../../specs/qa-chain-grounded-experience.md) define the exact route/track mapping.

Historical decision (2026-09-21): low confidence, missing key or judge failure forced clarify and missing live credentials blocked completion. The 2026-10-16 amendment supersedes those failure/fallback clauses, retaining Jev instead of MiniMax JSON on the configured classifier path. The trade-off is possible unnecessary retrieval in exchange for answering ordinary corpus questions when the optional judge is unavailable. Rejected alternatives remain a MiniMax fallback classifier or parallel text-model/Jev classification. This adopts the design without asserting implementation or live verification.
