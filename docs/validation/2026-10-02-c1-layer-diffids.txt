=== baked .pyc, re-counted 2026-10-02 =====================================

The T4 record's counts (1,099 .pyc baked, 787 differing) were taken from the
differing layer TARS. Re-counted here against the merged root filesystem, and
the two numbers are consistent, not contradictory: 1,099 is the count under
site-packages; 1,327 is every .pyc in the image.

  docker run --rm --network none --entrypoint /bin/bash fin-g4-pipeline:s2b1 \
    -c 'find / -xdev -name "*.pyc" -type f | wc -l'          # -> 1327
  docker run --rm --network none --entrypoint /bin/bash fin-g4-pipeline:s2b1 \
    -c 'find / -xdev -name "*.pyc" -type f | grep -c site-packages/'  # -> 1099
  docker run --rm --network none --entrypoint /bin/bash fin-g4-pipeline:r1 \
    -c 'find / -xdev -name "*.pyc" -type f | wc -l'          # -> 0
  # r1 additionally reports PYTHONDONTWRITEBYTECODE=1; s2b1 reports it empty.

All 1,327 paths are under /usr/local/lib/python3.12. Caveat: if you redirect
find's output to a file inside the container, find will count that file too and
report 1328. Write outside the container's filesystem, or subtract one.

=== per-file differing-path lists: NOT committed ==========================

The per-file evidence behind "8 differing in layer 4, 774 in layer 8, 13 in
layer 9" is not committed; only the digests above are. A reader can regenerate
it on a host holding s2b1 and s2b2 (needs ~600 MB of scratch per image):

  docker save fin-g4-pipeline:s2b1 -o s2b1.tar && mkdir -p a && tar -xf s2b1.tar -C a
  docker save fin-g4-pipeline:s2b2 -o s2b2.tar && mkdir -p b && tar -xf s2b2.tar -C b
  # layer N's tar is a/layer<N>/layer.tar, per index in manifest.json
  for n in 4 8 9; do
    (cd a/layer$n && find . -type f | sort | xargs sha256sum) > /tmp/a.$n
    (cd b/layer$n && find . -type f | sort | xargs sha256sum) > /tmp/b.$n
    diff /tmp/a.$n /tmp/b.$n | grep '^[<>]' | wc -l
  done

Path, mode, size, uid, gid and mtime were identical in all three layers; only
file content differed. Do not use `diff -r` on the extracted trees as a
substitute: it compares the merged result, which does not isolate a layer.
